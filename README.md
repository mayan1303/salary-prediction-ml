📌 Salary Prediction Using Linear Regression

This project predicts employee salary based on years of experience using a simple Linear Regression machine learning model.

📊 Tech Stack

Python

Pandas

Matplotlib

Scikit-learn

📁 Dataset

The dataset contains the following columns

YearsExperience

Salary

Dataset file: salary_data.csv

🚀 Project Workflow

Import and clean the dataset

Visualize salary vs years of experience

Split dataset into training and testing

Train Linear Regression model

Predict salary for test data

Plot regression line

📈 Sample Output

Scatter plot of actual data

Regression line of prediction

Salary prediction results

📒 Jupyter Notebook

All the code is available in:
salary_prediction.ipynb

📌 How to Run

Install dependencies:

pip install pandas matplotlib scikit-learn


Run Jupyter Notebook:

jupyter notebook salary_prediction.ipynb
